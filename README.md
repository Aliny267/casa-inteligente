# Casa Inteligente - Painel IoT

Projeto desenvolvido em React para simular um painel de controle de IoT (Casa Inteligente).

## 🚀 Como rodar
Se você clonou este repositório com `node_modules` incluso:
- Basta rodar `npm run dev` para iniciar o servidor local.

Se preferir instalar do zero:
- Rode `npm install` para instalar dependências.
- Depois `npm run dev`.

## 🛠️ Tecnologias
- React
- Vite
- Tailwind CSS
- DaisyUI
- Phosphor Icons

## 📌 Objetivo
Criar um painel de controle moderno, com Dark Mode e componentes tecnológicos, simulando integração com dispositivos IoT.
